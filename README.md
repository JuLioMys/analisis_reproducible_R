# Curso: Análisis de Datos Reproducible con el lenguaje R

Material del curso impartido por el **Dr. Julio Torres**. Repositorio con scripts, datos e imágenes utilizados durante las clases.

## Sobre el curso

Curso virtual de 24 horas (4 módulos, 12 clases de 2 hs) dirigido a estudiantes y profesionales que necesiten trabajar con datos tabulares (Excel, .csv, .txt, SQL). No requiere experiencia previa en programación.

**Objetivo:** aprender a analizar datos de forma reproducible, documentando todo el proceso para que pueda verificarse, colaborarse o reutilizarse.

## Contenido

| Módulo | Tema |
|---|---|
| 1 | Introducción al lenguaje R y RStudio |
| 2 | Manipulación y limpieza de datos con R (Tidyverse) |
| 3 | Visualización de datos con ggplot2 |
| 4 | Comunicar, compartir y colaborar con R (R Markdown + Git/GitHub) |

👉 **Programa completo, fundamentación y cronograma:** [ver documento](docs/programa_curso.md)

## Estructura del repositorio

- `clases/` — scripts de cada clase
- `datos/` — datos de ejemplo
- `imagenes/` — imágenes usadas en las clases
- `docs/` — documentación del curso (programa, cronograma)

## Cómo usar este material

1. Clona el repositorio o descárgalo como ZIP.
2. Abre `analisis_reproducible_iibp.Rproj` en RStudio.
3. Los scripts de cada clase están en `clases/`.
