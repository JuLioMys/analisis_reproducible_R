## Introducción

En este curso se imparten las bases conceptuales y se proveen las herramientas necesarias para analizar datos de una manera reproducible. El término “reproducible” aquí se aplica específicamente al método de trabajo moderno que facilita las tareas relacionadas al análisis de datos. Además, este método permite que otras personas puedan verificar, colaborar o reutilizar estas tareas documentadas. Muchas veces, es la misma persona que realizó el análisis la que meses o años después necesita repetir estas tareas. Estas herramientas hacen posible esa y otras tareas de una forma sencilla y sistemática.

El curso va dirigido a estudiantes y profesionales que necesiten trabajar con datos tabulares (Excel, .csv, txt, SQL). No es requisito manejar ningún lenguaje de programación ya que el curso está enfocado a personas sin ninguna base. La carga horaria y la distribución de contenidos también tiene muy en cuenta esto, ya que las clases están organizadas para ir ganando habilidades desde lo básico a tareas más complejas.

El curso es impartido de forma virtual. La plataforma, los días y horario es convenido con los estudiantes y el instructor. El programa se divide en 5 módulos con sus respectivos ejes temáticos y contenidos que se detallan mas abajo. La carga horaria sería de 6 hs por módulo, totalizando 24 hs reloj.

## Fundamentación

Analizar datos, tanto en un contexto académico como laboral requiere realizar tareas repetitivas. Generalmente, la limpieza de datos (ordenar, transformar, seleccionar, filtrar, etc) es la tarea que toma mayor cantidad de tiempo. Luego, durante los análisis exploratorios, con la elaboración de gráficos y tablas para mostrar resultados también son tareas que necesitan repetirse y modificarse por la dinámica natural de este tipo de trabajo. 

Las herramientas y las habilidades que se van a aprender durante el curso facilitan todas estas tareas, ya que al hacerlas del modo “reproducible” todo el proceso queda documentado y se vuelve relativamente sencillo “reproducir” el análisis en cualquiera de las etapas. La adopción de este método y las herramientas facilitará enormemente el trabajo del analista de datos, ahorra tiempo y reduce el error humano asociado a tareas repetitivas. Además, permite la comunicación efectiva de los resultados (reportes, presentaciones, etc) y la colaboración entre pares a través de repositorios.

## Contenido del curso

### Módulo 1: Introducción al lenguaje R y RStudio

- Análisis reproducible. Bases conceptuales.
- Instalación de R y RStudio.
- RStudio. Configuración del entorno, instalar librerías, buscar ayuda, gestión de proyectos, directorio de trabajo.
- R-base. Tipos de datos (numérico, carácter, factor, lógico), estructura de datos (vectores, matrices, data frames, listas y arrays), asignación a objetos y funciones.
- Selección, filtro, operaciones con vectores (comparación, lógicos, estadísticos).
- Importar y exportar datos (read.table, write.table).

### Módulo 2: Manipulación y limpieza de bases de datos con R

- Introducción Tidyverse: una colección de librerias de R que facilitan el tratamiento de datos tabulares (.csv, .xlsx, .txt, etc).
- Importar datos en distintos formatos (readr, readxl) y prepararlos para facilitar su uso (tibble). 
- Manejar y transformar datos (dplyr). Filtrar, seleccionar, reordenar, agrupar y resumir. 
- Operadores lógicos booleanos (&, |, !) y sus aplicaciones.
- Combinacion de multiples operaciones con “pipe” ( %>%).
- Operaciones varias con datos tabulares: pivotar de formato “largo” a “ancho”, separar y unir columnas, unir tablas en base a diferentes criterios.

### Módulo 3: Visualización de datos y gráficos con R

-  Introducción a la visualización de datos y la “gramática de los gráficos”.
-  Introducción a ggplot2, estructura (Layers, labels, themes, facets) y su sintaxis. 
-  Modificar y personalizar los gráficos (cambiar colores, agregar títulos, crear leyendas, etc).
-  Múltiples gráficos en una sola figura (Facet_wrap, Facet_grid).
-  Crear y personalizar diferentes gráficos según tipo de datos (barchart, boxplot, histogram, scatterplot, etc).
-  Gráficos interactivos (ggploty).

### Módulo 4: Comunicar, compartir y colaborar con R

- Introducción a R Markdown. Una librería que integra texto, código y resultados.
- Elementos básicos de R Markdown, formateo de texto, bloques de código y formatos de salida (pdf, word, presentación).
- Introducción al Control de Versiones,  Git y Git Hub.
- Instalar Git y crear un repositorio en Git Hub.
- Conectar un proyecto en Rstudio con un repositorio de Git Hub.
- Realizar modificaciones en el proyecto local, documentarlo (commit) y enviarlo al repositorio (push).
